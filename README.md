Промт

Сделай приложение для Windows – таймер помодоро. Период работы задаётся пользователем 
в окнах «Работа» и «Перерыв» в минутах. По умолчанию устанавливается 25 минут в окне 
«Работа» и 5 минут в окне «Перерыв». Цвет окна – жёлто-зелёный. Оконце значения работы – 
оранжевый цвет, а перерыва – голубой цвет. Значения таймеров должны быть чёрного цвета. 
В шапке – «Таймер помодоро – эффективность в работе». Приложение должно запускаться без 
предустановки по клику ярлычка. Активация таймера «Работа» должна производиться кнопкой 
«Работа» бледного оранжевого цвета. После активации кнопка должна окрашиваться в 
ярко-оранжевый цвет. Кнопка активации таймера «Перерыв» должна производиться кнопкой 
«Перерыв» бледно-голубого цвета. После активации эта кнопка должна окрашиваться в 
ярко-голубой цвет. После завершения счёта кнопки активации должны принимать бледный 
оттенок исходного цвета, а значения в окнах принимать заданные значения.
Если в процессе счёта времени работы кликнуть на кнопку «Перерыв», приложение должно 
перейти в режим «Перерыв», и наоборот для режима «Работа». Повторный клик на активную 
кнопку останавливает режим счёта, цвет кнопки принимает бледное значение исходного кода, 
значения счёта сохраняются. При следующем клике счёт возобновляется.
Напиши простой код, используемый в Windows.
